## 📝 Create Your First Landing Page (3 Minutes)

### Step 1: Start Creating (30 seconds)

1. Go to Dashboard
2. Click **"Landing Pages"** in the sidebar
3. Click **"Create Landing Page"** button

### Step 2: Choose Template (1 minute)

You'll see a grid of beautiful templates with preview images:

**Restaurant Templates:**
- **Modern Restaurant Hero** - Full-screen hero with food photos
  
**Business Templates:**
- **SaaS Product Launch** - Modern product showcase with features

**Retail Templates:**
- **Product Showcase** - E-commerce product display with gallery

**Real Estate Templates:**
- **Property Listing** - Professional property showcase

**Event Templates:**
- **Event & Conference** - Event promotion with registration

**How to choose:**
- Browse different categories using the filter buttons
- Click any template to see a preview
- Click "Next: Customize" when ready

### Step 3: Name Your Page (30 seconds)

1. **Page Name**: Enter a name (e.g., "My Restaurant Menu")
2. **URL**: Auto-generated, or customize it (e.g., `my-restaurant`)
3. Click **"Create & Open Visual Editor"**

### Step 4: Edit Visually (1 minute)

The visual builder opens with your template fully loaded:

**Edit Text:**
- Click any text to edit it directly
- No HTML or code needed!

**Replace Images:**
- Click any image field in the right panel
- Browse curated stock photos
- Search Unsplash for millions more
- Click to select - updates instantly!

**Add Sections:**
- Drag new sections from the left panel
- Hero, Features, Gallery, CTA, Contact, Menu

**Reorder Sections:**
- Drag sections up/down to reorder

**Configure Properties:**
- Select any section
- Adjust colors, sizes, styles in right panel

### Step 5: Publish (10 seconds)

1. Click **"Publish"** button at top
2. Your page goes live immediately!
3. Share the URL with anyone

## 💡 Pro Tips

### Customizing Templates

**Change Colors:**
1. Select any section
2. In right panel, find color properties
3. Use color picker or enter hex codes

**Change Fonts:**
- Fonts are defined in template metadata
- Coming soon: Font picker in builder

**Adjust Spacing:**
- Most sections have padding/margin controls
- Use the right panel to adjust

### Image Best Practices

**Hero Images:**
- Use high-resolution (1920x1080 or larger)
- Ensure good contrast with text
- Use overlay opacity control

**Gallery Images:**
- Keep consistent aspect ratios
- Use high-quality photos
- Compress before uploading (coming soon)

**Stock Library:**
- Curated by category
- All images licensed for commercial use

### Building Strategy

**Start with a template:**
- Don't start from scratch
- Templates give professional structure
- Easier to customize than build new

**Mobile-first:**
- All templates are mobile-responsive
- Test on different screen sizes
- Use browser dev tools

**Keep it simple:**
- 3-5 sections is usually enough
- Too much content overwhelms visitors
- Clear call-to-action is key

## 🔧 Common Tasks

### Replace an Image

1. Select the section with the image
2. In right panel, find the image field
3. Click the image/button
4. Browse stock library or search
5. Click to select - updates instantly!

### Add a New Section

1. Find "Components" panel on the left
2. Drag a section type to the canvas
3. Drop it where you want it
4. Configure in right panel

### Reorder Sections

1. Hover over a section
2. Grab the drag handle (⋮⋮)
3. Drag up or down
4. Drop in new position

### Delete a Section

1. Select the section
2. Press Delete key, or
3. Click trash icon in right panel

### Duplicate a Section

1. Select the section
2. Click duplicate icon
3. Edit the copy

### Change Button Text/Link

1. Select section with button
2. In right panel:
   - Find "Button Text" field
   - Find "Button Link" field
3. Edit and save

## 🚀 Advanced Features

### Auto-Save

- Changes save automatically every 3 seconds
- See "Last saved" timestamp at top
- Never lose your work!

### Draft vs Published

- **Draft**: Your working version (private)
- **Published**: Live version (public)
- Edit draft freely without affecting live page
- Publish when ready

### Preview Before Publishing

- Click "Preview" button
- See exactly how it will look
- Test on different devices
- Publish with confidence

### Connect to QR Code

When creating a landing page from QR code flow:
1. Create QR code first
2. Select "Landing Page" as destination
3. Click "Create Landing Page"
4. Auto-connects to QR code

### Custom Domain (Coming Soon)

- Point your own domain to landing page
- E.g., `www.myrestaurant.com`
- SSL certificate included

## ❓ FAQs

### Can I use my own images?

**Coming soon!** Image upload feature is being added. For now, use:
- Stock library (curated images)
- Unsplash search (millions of free images)

### Can I edit the HTML/CSS?

Not directly in the visual builder. The builder gives you:
- Pre-designed components
- Visual customization options
- Professional results without coding

For advanced customization, contact support about custom development.

### Are templates free?

Yes! All 5 templates are free. More templates (including premium) coming soon.

### Can I change templates later?

Not recommended. Each template has a unique structure. Better to:
1. Start with right template
2. Customize heavily if needed
3. Or create new page with different template

### What happens to my old landing pages?

Old HTML-based pages still work! To upgrade them:
1. Run migration script (see docs)
2. Or recreate manually with new templates

### Can I export my page?

Not currently. Pages are hosted on our platform. Custom domain support coming soon.

### How do I add a menu?

Use the MenuSection component:
1. Drag "Menu Section" from left panel
2. Configure categories and items
3. Or use Menu Manager tab (for restaurants)

### Can I add custom forms?

Contact section includes basic form. For advanced forms:
1. Use third-party form builder (Typeform, Google Forms)
2. Embed link as button/CTA
3. Or contact support for custom forms
