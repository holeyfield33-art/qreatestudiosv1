# QR Templates Quick Start

## 🚀 Get Started in 3 Steps

### 1. Browse Templates
Visit the template gallery:
```
/dashboard/templates
```

### 2. Find Your Template
- **Search**: Type keywords like "menu", "social", "payment"
- **Filter by Category**: Click category buttons (🍽️ Restaurant, 💼 Business, etc.)
- **Premium Toggle**: Show only premium templates
- **Favorites**: Click ❤️ to save favorites

### 3. Apply & Create
1. Click any template card
2. Auto-redirects to QR creation page
3. Template applied with all styling
4. Fill in QR details (name, URL, etc.)
5. Click "Create QR Code"

## 💡 Tips

### For Best Results
1. **Match to purpose**: Choose template matching your use case
2. **Check contrast**: Template shows contrast ratio validation
3. **Premium features**: Gradients and advanced styles require premium
4. **Test scanning**: Always test QR code after creation

### Template Features

**Dot Styles**:
- `square`: Traditional QR look
- `rounded`: Softer corners
- `dots`: Circular dots
- `classy`: Elegant curves
- `extra-rounded`: Very soft

**Error Correction**:
- `L` (7%): Standard environment
- `M` (15%): Most common (recommended)
- `Q` (25%): Higher reliability
- `H` (30%): Maximum reliability (with logos)

**Frame Types**:
- `none`: No frame
- `basic`: Simple border
- `rounded`: Rounded corners
- `shadow`: Drop shadow effect
- `badge`: Bold badge style

## 🐛 Common Issues

**Template not applying?**
- Check URL has `?template=` parameter
- Verify template ID is valid
- Clear browser cache

**Colors look wrong?**
- Check monitor calibration
- Verify hex color format
- Test in different lighting

**Can't find template?**
- Use search function
- Check category filters
- Clear all filters and browse
